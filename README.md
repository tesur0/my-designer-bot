# Telegram-бот "Тренер по продажам"

Бот помогает digital-дизайнеру разбирать переписки с клиентами, формулировать ответы и тренировать продажи через ролевые игры.

## Запуск

1. Установить зависимости:

```bash
pip install -r requirements.txt
```

2. Добавить переменные окружения:

```bash
TELEGRAM_BOT_TOKEN=токен_бота
ANTHROPIC_API_KEY=ключ_anthropic
```

Опционально:

```bash
ANTHROPIC_MODEL=claude-sonnet-4-20250514
```

3. Запустить:

```bash
python3 designer_bot.py
```

## Команды

- `/start` - короткая инструкция
- `/help` - что умеет бот
- `/rules` - 8 принципов коммуникации
- `/roleplay` - тренировка с клиентом
- `/stop` - остановить тренировку

## Как пользоваться

Отправь текст, пересланное сообщение или скрин переписки. Если скринов несколько, отправь их подряд - бот подождёт 5 секунд и разберёт всё одним запросом.
